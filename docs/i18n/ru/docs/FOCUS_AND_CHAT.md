# Фокус и совместимость с Chat

Существуют ровно один браузер и один нативный владелец фокуса: BrowserService. UiCoreBridge принимает только проверенные запросы host. ChatBridge и отдельный Chat-репозиторий по содержанию не меняются.

Приоритет: меню Skyrim → верхнее UI-меню/отображение → Chat → игра. Новые UI-меню закрывают ввод чата существующим ChatBridge, сохраняя черновик. Enter по-прежнему открывает чат без сфокусированного UI-меню. В форме Enter/Tab — обычные клавиши браузера. Escape закрывает сначала отображение, затем верхнее UI-меню, затем чат. Несколько меню показаны ограниченным стеком с одним активным диалогом.

F2 скрывает/показывает тот же CEF и при скрытии освобождает ввод. Enter/F6 могут вновь показать скрытый CEF. F6 при активном UI-меню закрывает верхнее, иначе сохраняет прежнее переключение фокуса чата. Второй регистрации клавиш и новых глобальных hotkey нет.

Инвентарь, карта, консоль, диалоги, загрузка и другие `badMenus` форка приостанавливают UI-взаимодействие и возвращают мышь/клавиатуру Skyrim. После закрытия ещё действительное меню получает фокус. Закрытие HUD/disconnect освобождают фокус; disconnect/смена сервера очищают приватные widgets/меню. UI-Core-timeout, error-boundary и снятие плагина освобождают только фокус UI Core, оставляя независимо открытый чат работоспособным.

Widgets/notifications имеют pointer-events none. Меню, кнопки и явно открытые параметры отображения интерактивны. У диалогов семантические подписи, навигация с клавиатуры, видимые границы фокуса. Масштаб 75–150%, текст вместе с цветовыми/списочными обозначениями. Модальные окна удерживают Tab внутри. Немодальные меню используют тот же осознанный режим ввода CEF без полноэкранного затемнения.

Автоматически проверены настоящие исходники BrowserService/ChatBridge/KeyboardEventsService, вложенные меню, F2/F6/Enter/Escape, инвентарь/карта/консоль/диалог/загрузка, два браузера production-root, нативные Scamp-боты и самостоятельный Chat. Нативные callbacks SkyrimPlatform для браузера/клавиатуры/меню даёт harness. Настоящее подавление клавиатуры/мыши в Skyrim и рендеринг CEF остаются ручной приёмкой.

## Редактор компоновки с 1.1.0

/UiEdit приходит через неизменённый реестр Chat и открывает только свой редактор. Приоритет фокуса как у параметров отображения, выше текущего plugin-меню. Escape/F6 отменяет черновик и возвращает в нижележащее меню/игру. Сохранение закрывает редактор по тем же правилам. Меню Skyrim приостанавливают/восстанавливают его; disconnect завершает полностью. Детали и клавиатурное управление — UI_EDITOR.md.
