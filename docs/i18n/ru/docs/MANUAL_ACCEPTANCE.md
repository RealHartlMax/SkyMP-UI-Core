# Ручная приёмка с двумя клиентами (открыта)

Список намеренно не отмечен пройденным. Автоматические нативные боты/браузеры отдельно описаны в VALIDATION.md. Нужны два настоящих Skyrim-клиента с одинаковым runtime-пакетом и тестовый игровой сервер.

Подготовка: обычным способом установить/включить SkyMPUICore, ExampleUiConsumer, SecondUiConsumer и существующий SkyMP Chat. UI Core первым. Полностью перезапустить сервер. Обоим игрокам использовать новый runtime-каталог, перезапустить Skyrim, подключиться обычно, без devUi/admin. Для приватных тестов не использовать реальные секретные значения.

- [ ] Safe-discovery: новый плагин отключён; включение/второй старт действительно загружают API v1.
- [ ] Оба игрока видят status-widgets двух независимых плагинов в обычном игровом CEF.
- [ ] A подтверждает диалог: лишь A видит счётчик 1/успех; B остаётся 0.
- [ ] Серверное изменение widget действительно видно в окне Skyrim.
- [ ] Кнопка вызывает ровно один handler с правильным native user/actor ID.
- [ ] Поздний CEF/reload/reconnect дают актуальные снимки без дублей listener/widget.
- [ ] Смена сервера/disconnect удаляет приватные состояния, полностью освобождает мышь/клавиатуру.
- [ ] A не видит адресованные только B widget/menu/notification, и наоборот.
- [ ] HTML/JS-подобный текст остаётся читаемым, без выполнения.
- [ ] Enter открывает Chat; A/B видят сообщения по одному разу; private-ответы приватны.
- [ ] Escape закрывает отображение/верхнее modal/ввод чата, возвращает игру; черновик остаётся.
- [ ] F2 выкл/вкл, F6 с Chat/modal, удержанный Enter, несколько modal не теряют фокус.
- [ ] Инвентарь/карта/консоль/диалог/загрузка/HUD не блокируют ввод Skyrim навсегда.
- [ ] Tab/Shift+Tab остаются в диалоге; кнопки с клавиатуры; текст читаем при 75/100/150%.
- [ ] Позиция/видимость только локальны; отказ storage не вызывает crash.
- [ ] config.locale=de/en и изменения locales/de.json/en.json видны после server-restart без client-rebuild.
- [ ] Недостающий locale-key имеет разумный fallback; неверная config даёт понятную ошибку старта.
- [ ] Без server-плагина UI Core пуст, прежний чат работает.
- [ ] Без нового client-пакета сервер пишет handshake-диагностику без crash/бесконечного retry.
- [ ] Protocol-mismatch блокирует actions; старые request-ID/чужие identity/permissions не действуют.
- [ ] 20 widgets с быстрыми updates остаются в лимитах очереди/байтов/частоты.
- [ ] Реально скачанные байты совпадают с опубликованными catalog/manifest.

Для каждого теста записать результат, дату, client/Skyrim/server/plugin-версии, при необходимости журнал/видео. Лишь после этого полностью доказано исходное определение готовности с настоящим игроком.
