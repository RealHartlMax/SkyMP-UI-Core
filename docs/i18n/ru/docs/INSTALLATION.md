# Установка, эксплуатация и обновление

<a id="gameserver"></a>
## Игровой сервер

Определите настоящий game-CWD по startup-script/процессу: `Plugins/` ищется относительно **него**. В обычных пакетах это `Server/`. Не создавайте дополнительный `Server/` внутри рабочего каталога запущенного сервера.

```text
<game-cwd>/Plugins/SkyMPUICore/
  plugin.json
  index.cjs
  config.json
  locales/de.json
  locales/en.json
  README.md
```

`SkyMPUICore-1.1.0.zip` содержит SkyMPUICore; распаковать в `Plugins/`. Один ZIP там оставлять нельзя. В discovery-режиме `safe` один раз запустить/перезапустить сервер для обнаружения. Затем панель **Ресурсы → Серверные плагины → Включить**, затем ещё один полный запуск. Известные плагины сохраняют включение.

Пример существующего ключа server-settings:

```json
{
  "pluginsLoadOrder": ["skymp-ui-core", "skymp-chat", "example-ui-consumer", "second-ui-consumer"]
}
```

Дополняйте существующий порядок, не заменяйте приватный server-settings.json. UI Core не зависит от Chat. Примеры ставятся только для тестов. Загрузчик декларативные зависимости не разрешает. Потребители при старте проверяют API v1 и выбирают конечный необязательный fallback.

Статус панели «running» при текущем `requireTemp` не доказывает запуск: в журнале нужна строка `Ready: API v1, frontend protocol v1`, в процессе сервера должен быть `globalThis.skympUi.getStatus()`.

<a id="konfiguration-und-sprache"></a>
## Конфигурация и язык

Стандартный путь: `<game-cwd>/Plugins/SkyMPUICore/config.json`. Либо до запуска задать `SKYMP_UI_CONFIG` абсолютным или относительным к game-CWD путём. Тогда `locales/` ищется рядом именно с этой конфигурацией, никогда не относительно временного entry. Максимальный размер конфигурации 16 KiB.

```json
{
  "locale": "de",
  "logLevel": "info",
  "maxWidgets": 20,
  "maxMenus": 4,
  "maxNotifications": 8,
  "maxStateBytes": 8192,
  "maxSessionBytes": 49152,
  "flushMs": 100,
  "updatesPerSecond": 50,
  "updateBurst": 100,
  "widgetTtlMs": 300000,
  "menuTtlMs": 120000
}
```

Остальные defaults/пределы — `src/config.ts`. Неизвестные ключи и значения вне протокола отклоняются; не обходите ошибку произвольно большими лимитами. Журналы: debug/info/warn/error, обычно без содержимого payload/токенов. Info по умолчанию достаточно.

Языки `de`/`en`. Оба JSON в `locales/` имеют одинаковые ключи. Меняйте только строки; код и HTML не нужны. Недостающие ключи используют встроенный перевод того же языка; отсутствие файла даёт уведомление. Неверный JSON, неизвестные ключи, пустые/длинные значения дают явную ошибку старта. После изменения текста/настроек перезапустить сервер; client-runtime пересобирать не нужно.

Игрок открывает параметры отображения кнопкой в сфокусированном CEF, например после F6/открытия UI-меню, меняет масштаб/позицию/видимость и язык представления. Язык сервера остаётся стандартным. Тексты сторонних widgets/меню/уведомлений локализует их плагин.

<a id="clientdateien-und-neustarts"></a>
## Клиентские файлы и перезапуски

Без подходящих client/CEF-файлов UI Core контролируемо пуст; сервер через 15 секунд при подключённом actor сообщает отсутствие frontend-handshake. При protocol-mismatch actions блокируются. Автоматической клиентской установки этим серверным плагином нет. См. CLIENT_DEPLOYMENT.md.

| Изменение | Перезапуск |
| --- | --- |
| Установка/включение/обновление плагина, config/locales | полный перезапуск игрового сервера |
| Client-script или CEF | закрыть Skyrim, подготовить Launcher, запустить Skyrim заново |
| Только UI-Core-плагин или язык | dashboard/starter перезапускать не надо |
| Сам dashboard/server-starter | его отдельный перезапуск по инструкции форка |

Перезапуск сервера отключает игроков. UI Core не поддерживает hot-reload плагинов и перенос чужих регистраций между процессами.

<a id="upgrade--rückkehr-zum-vorherigen-stand"></a>
## Обновление / возврат к прежнему состоянию

Сначала сохранить копии каталога, конфигурации, локальных переводов и discovery-state. При обновлении предпочтительно заменять `index.cjs`, manifest, поставляемые docs/types; приватные config/locales не перезаписывать вслепую. Новые defaults переносить выборочно. Имя плагина остаётся `skymp-ui-core`.

При смене client-протокола сначала проверить согласованную пару client/server. Старые runtime-каталоги сохранить; при проблемах вернуть каталог к прежнему проверенному manifest и загрузить соответствующий server-плагин. Затем перезапустить сервер и затронутые Skyrim-клиенты. Локальные ZIP не являются live-публикацией. После загрузки отдельно проверить production-каталог и transport-байты.
