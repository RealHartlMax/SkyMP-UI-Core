# ExampleUiConsumer

Самостоятельный тестовый плагин. Загружать после UI Core. После успешного frontend-ready в обычном CEF-root появляются status-widget и подтверждающий диалог. Кнопка обновляет приватный widget, сообщает успех, закрывает меню. Авторизация проверяет native user/actor; chat-команды не нужны. Без UI Core необязательный плагин контролируемо отключён. Без server-update widgets истекают через пять минут. Это пример интеграции, не игровое значение. Ставить только для приёмки/тестового сервера.
