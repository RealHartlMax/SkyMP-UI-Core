# ExampleUiConsumer

Standalone test plugin. Load after UI Core. On successful frontend readiness, a status widget/confirmation dialog appear in normal CEF root. Button updates private widget, reports success and closes menu. Authorization checks native user/actor mapping; no Chat commands needed. Without UI Core this optional plugin stays deliberately disabled. Widgets expire after five minutes without server update. Display is an integration example, not a game value. Install only for acceptance/test servers.
