# ExampleUiConsumer

Eigenständiges Testplugin. Nach UI Core laden. Beim erfolgreichen Frontend-Ready
erscheinen ein Statuswidget und ein Bestätigungsdialog im normalen CEF-Root.
Der Button aktualisiert das private Widget, meldet Erfolg und schließt das Menü.
Die Freigabe prüft native User-/Actor-Zuordnung; keine Chatbefehle notwendig.
Ohne UI Core bleibt dieses optionale Plugin kontrolliert deaktiviert.
Widgets laufen nach fünf Minuten ohne Serverupdate ab. Die Anzeige ist ein
Integrationsbeispiel, kein Spielwert. Nur für Abnahme/Testserver mitinstallieren.
